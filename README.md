# 猫吃了吗

一款给挑食猫主人使用的轻量试吃档案。目前优先做成可安装的 H5 / PWA：打开后立即记录新品或已有食物的表现，并在补货时查看当前有效的判断。

## 当前 H5 已实现

- 首页以“立即记录”为第一任务，没有展示型大 Hero。
- 新品支持包装照片、食物类型、品牌、名称、口味和质地。
- 已有食物可以直接补一次反馈，不重复拍照。
- 五种反馈：主动吃、正常接受、勉强吃、埋屎拒绝、没法判断。
- 只计算滚动 90 天内的正向反馈；历史记录永久保留。
- 近 90 天累计 3 次正向后进入放心买，过期后进入待复验。
- 埋屎拒绝后支持手动“再给一次机会”。
- 补货清单支持状态分组、关键词搜索和食物类型筛选。
- 数据使用浏览器本地存储，照片会先压缩。
- 包含 PWA Manifest、桌面图标和离线缓存。
- 邀请链接中的邀请码会绑定本地体验 ID；真正的多人同步仍需下一阶段后端。

## 工程结构

```text
cat-eat-miniapp/
├── preview/             # 当前可用的 H5 / PWA
│   ├── index.html
│   ├── preview.css
│   └── preview.js
├── manifest.webmanifest # PWA 安装信息
├── sw.js                # 离线缓存
├── utils/
│   ├── rules.js         # H5 与小程序共用的状态规则
│   └── store.js         # 原小程序本地存储
├── tests/               # 规则单元测试
├── pages/               # 保留的微信小程序页面
└── docs/                # MRD、PRD 与交互架构
```

## 本地运行

```bash
npm install
npm test
npm run preview
```

打开 `http://127.0.0.1:4173/?screen=home`。

可从空状态载入示例数据，也可以直接建立真实食物。测试邀请码入口可使用：

```text
http://127.0.0.1:4173/?screen=home&invite=你的邀请码
```

当前邀请码只建立本地体验身份，不会跨设备同步。给 2–3 位真实用户测试前，需要再接一个轻量后端。

## 微信小程序

原微信小程序代码仍保留在 `pages/`、`components/`、`app.*` 和 `project.config.json` 中，但当前不作为首发载体。

如需验证原小程序：

```bash
npm run validate
```

## 视觉资产

整个 H5 使用轻盈、接近 iOS 的视觉语言：以 `#FAFAFA` 为基础画布，在页面背景保留低饱和蓝、紫、粉、薄荷色弥散；普通组件主要通过半透明白、细描边和局部磨砂建立层级，不使用外投影。投影只保留给头像、模态弹层和系统提示。品牌绿用于正向判断和提交，系统蓝用于编辑、查看与拍照等普通动作。

猫、相机、罐头、爱心、眼睛、包裹和禁止图标来自开源项目 [Phosphor Icons](https://github.com/phosphor-icons/core) 的 Duotone 系列（MIT License）。许可证副本位于 `assets/icons/PHOSPHOR-LICENSE-MIT.txt`。

底部导航使用 Phosphor 的 House、Plus 和 List Bullets 图标，并通过 Regular、Bold 与 Fill 字重表现未选中、核心操作和当前页面状态。它们与页面内其他图标共用 `assets/icons/PHOSPHOR-LICENSE-MIT.txt`。
