# 猫吃了吗品牌色卡

品牌主色以 `#4571FC` 为中心。蓝色负责交互、选择和操作反馈；绿色、黄色、红色只表达食物状态和猫咪反馈，不参与普通选中态。

## 品牌蓝色阶

| Token | 色值 | 用途 |
|---|---|---|
| `--brand-50` | `#F3F6FF` | 页面提示、极浅选中背景 |
| `--brand-100` | `#E8EEFF` | 图标选中底色 |
| `--brand-200` | `#D3DEFF` | 浅分隔与辅助底色 |
| `--brand-300` | `#ADC1FF` | 弱描边 |
| `--brand-400` | `#7F9CFF` | 辅助强调 |
| `--brand-500` | `#5D7FFF` | 强调过渡色 |
| `--brand-600` | `#4571FC` | 品牌主色、Tab、筛选、导航 |
| `--brand-700` | `#315AE0` | 按压态、白底可访问链接文字 |
| `--brand-800` | `#294BB8` | 浅蓝背景上的深色文字 |
| `--brand-900` | `#263F91` | 高对比强调文字 |

## 角色规则

- 品牌交互：主按钮、状态 Tab、类型筛选、选中反馈项、焦点、编辑和查看动作使用品牌蓝；小号文字和按钮底色使用对比度更高的 `--brand-700`。
- 正向语义：`放心买`、`主动吃`、回购进度继续使用绿色。
- 观察语义：`待复验`、`勉强吃`使用黄色。
- 警示语义：`埋屎避雷`使用红色。
- 中性语义：`不补货`、`没法判断`使用灰色。

白底的小号品牌文字优先用 `--brand-700`；`--brand-600` 主要用于图标、描边、选中指示线和大面积按钮，避免小字对比度不足。
